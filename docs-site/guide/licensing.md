## 声音复刻与训练数据

公开数据集或 GitHub 仓库可下载，不自动证明上传者有权把底层游戏音频再许可给你。训练前至少记录：

1. 原始音频来源与权利人。
2. 数据集声明的许可证及其是否覆盖音频内容。
3. 配音演员、角色 IP 与模型服务条款对复刻/再分发的限制。
4. checkpoint、示例 WAV 与商业使用的具体边界。
5. 删除/撤回机制和你的适用地区要求。

模型 manifest 中写一个 SPDX ID 不能替代这项审查。
