# 许可、品牌与私有资产

ChatWaifu NEXT 的仓库发行许可证目前尚未选定。代码、文档、第三方依赖、模型、声线、Live2D SDK/Core、
角色模型与原作 IP 是不同权利层；“本机能运行”不代表“可以公开分发或商用”。

本文档站通过独立的 public GitHub Pages 发布仓库托管；它只包含构建后、经过审计的说明和示意图。
规范源仍在 private 产品仓库中，文档公开不会改变源码权限，也不会授权任何未随文档发布的本地资产。

模型仍保持 Git 忽略和私有，公开发行前必须单独复核原发布条款与角色权利边界。

## 声音复刻与训练数据

公开数据集或 GitHub 仓库可下载，不自动证明上传者有权把底层游戏音频再许可给你。训练前至少记录：

1. 原始音频来源与权利人。
2. 数据集声明的许可证及其是否覆盖音频内容。
3. 配音演员、角色 IP 与模型服务条款对复刻/再分发的限制。
4. checkpoint、示例 WAV 与商业使用的具体边界。
5. 删除/撤回机制和你的适用地区要求。

模型 manifest 中写一个 SPDX ID 不能替代这项审查。

- 为仓库选择明确许可证，并检查是否与所有 bundled 依赖兼容。
- 生成第三方 notices、模型卡、数据来源与 Worker Pack license metadata。
