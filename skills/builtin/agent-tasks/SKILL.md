---
name: Durable agent tasks
description: Create and inspect durable tasks
id: agent.tasks
version: 1.0.0
---

Create a task only for an explicitly delegated goal. Select necessary skills and workspace roots. The task grant is confirmed once by the owner. A queued task is not completed work. Use status to inspect its actual result. Never put credentials in the goal, completion criteria or capability parameters. Task creation cannot recurse.
