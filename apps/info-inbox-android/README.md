# 信息收件箱 Android

独立 Gradle 模块，复用 Runtime 的信息整理、知识同步与图检索接口。业务库为 App 私有 SQLite；微信原文归档与 Root 配置留在手机。

## 构建

需要 JDK 17、Android SDK 36 / Build Tools 36.0.0；通过 `ANDROID_HOME` 或未入库的 `local.properties` 指定 SDK。

```sh
cd apps/info-inbox-android
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
python3 -m unittest discover -s tests/python -v
```

Debug 默认使用本机生成的开发签名。正式升级现有手机时，通过 `INBOX_SIGNING_KEY` 指向原签名文件，并设置对应的 `INBOX_SIGNING_PASSWORD`、`INBOX_SIGNING_ALIAS`、`INBOX_SIGNING_KEY_PASSWORD` 和 `INBOX_SIGNING_STORE_TYPE`；默认值兼容现有本机 PKCS12 开发签名。签名文件及密码保留在本机或 CI Secret 中。未配置签名时 Release 产物为未签名 APK。

```sh
./gradlew :app:assembleRelease :app:lintRelease
```

首次使用需要本人手机已有经验证的 Root 采集配置；本模块不包含微信账号、数据库密钥或聊天数据库。仓库内 Root 运行库的来源和许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。新手机配置、Root 授权、通知和提醒权限需要真机验收；CI 不读取微信或提交真实资料。

## 0.4.4 群和好友排除

## 0.4.2 新消息整理与反馈

采集归档到 AI 队列时优先选择最新消息；分析批次优先取最近资料，然后将选中资料按原消息顺序提交模型。旧资料保留并逐步补齐，长消息仍按分段顺序处理，已有进度保留。

原文列表及详情显示等待入队、等待整理、正在整理、已整理及无待确认事项等状态。消息详情提供“查看这条消息的 AI 整理结果”，只显示当前来源修订的相关建议。AI 建议页显示队列进度、会话与消息时间；显示期间每 15 秒检测变化并刷新，保留滚动位置，打开弹窗时暂停刷新。

所有组件在默认进程内运行。Application 启动时、任何工作线程启动前，回收上一进程遗留的批次租约；重新排队尚未完成部分并清空旧批次输入，不修改已完成进度、建议或确认记录。旧批次结果仍受租约校验保护。该恢复方法仅在应用进程启动时调用，不在普通数据库连接时调用。

18 项单元检查、Debug/Release 编译与 Lint 通过。真机 FlowInstrumentation 的 102 项断言覆盖新消息优先、选中批次按时间提交、逐条进度、无建议结果、来源修订、旧批次重启恢复与旧结果拒绝。实际目标消息从未入队转为已处理，生成一条待确认建议。验收通过系统调度器的受控任务触发完成；手机当时锁屏，未进行可见界面验收。已安装并核对 Release APK 哈希，自动整理与宁宁连接保留。

本版不修改数据库 schema 或服务端代码。私有升级备份保存在手机 `/data/adb/wechat-collector/backups/info-inbox-before-0.4.2.db`，保持 0600。
