# Documentation brand assets

The documentation site uses two original generated images:

- `docs-site/public/brand/chatwaifu-mark.png`: transparent crescent, ribbon, and star emblem.
- `docs-site/public/brand/moonlit-room.png`: original moonlit room illustration for the public homepage and README.

Both were generated with the built-in OpenAI image generation tool on 2026-08-30. The prompts explicitly
excluded characters, recognizable game assets, text, logos, circuitry, and imitation of an existing game scene.
The room was composed with dark negative space for documentation copy; the emblem was generated with real alpha
transparency and then resized without altering its design.

Source-generation files remain outside the repository. Committed PNGs are the canonical project copies.
