# 密码登录与知识图谱设置入口发布：2026-10-14

## 已上线的行为

- 公网 Runtime 根地址提供登录/产品页面；`/settings/connection` 可设置和修改密码。
- “设置 → 记忆与资料 → 知识图谱”跳转到独立的 `/knowledge` 画布，图谱可返回
  `/settings/knowledge`。关系清单继续支持不用点击画布即可选择关系。
- 新密码支持 12-128 个字符，保留中文、符号和首尾空格。密码验证后换取短期
  Runtime 凭据，客户端不会持久保存密码。原管理令牌继续可用。
- 本次没有为所有者选定或设置密码。所有者需在已登录的连接设置页完成首次设置。
