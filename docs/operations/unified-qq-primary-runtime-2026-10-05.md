## 备份与恢复约束

一致数据库、配置、加密凭据和私有核验记录保存在
`/home/mubai/chatwaifu-server/backups/qq-unify-20261005-19fd808`。
`primary-before.sqlite`、`qq-before.sqlite` 是两个 Runtime 均停止后的副本，
`merged.sqlite` 是上线前完整验证的副本。目录及凭据保持仅宿主用户可读。
操作记录为 `CUTOVER.json`、`UNIFIED-VERIFIED.json` 和
`SEMANTIC-REBUILD-VERIFIED.json`。

合并实例产生新业务事实后，不能直接用迁移前的主数据库覆盖它。恢复独立 QQ
前，必须先停止主 Runtime 的 QQ 接入、保存最新数据并协调新增会话/消息/记忆，
再移除独立 Runtime 的启动保护及恢复原服务。此次没有执行回退或恢复旧库，
原两个部署的源码、状态和备份均保留。

迁移工具为
[`tools/merge_qq_runtime_database.py`](../../tools/merge_qq_runtime_database.py)，
要求输入版本一致、无进行中任务且会话身份不重叠；只写新副本，不覆盖输入，
也不迁移凭据、启动渠道或直接安装到在线数据库。
