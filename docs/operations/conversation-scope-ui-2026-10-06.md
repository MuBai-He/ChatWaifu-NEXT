# 对话范围与参与者弹窗修正

2026-10-06，在 `mubai/messaging-short-replies` 隔离工作区直接实现与审查，未使用 AGY。

## 功能与名称来源

“对话范围”选择桌宠 / Web 当前的说话者，以及独立对话或固定听众共享场景。
独立对话按参与者延续记忆；共享场景使用该场景的记忆，切换关闭之前的通话。
它不启用 QQ 群，也不授予群成员发言权限；这些设置仍由渠道管理负责。

现场 GET participants 中四位 QQ 成员的名称确实保存为“QQ 群成员 + 号码”。
这不是 React 丢掉了昵称。NapCat 成员接口能够提供昵称和群名片，但原有
注册记录使用了占位名，而且参与者接口此前只能创建、不能修改名称。

新增 operator-only `PATCH /v1/participants/{participant_id}`：
`display_name` 为 1–80 字符，`expected_display_name` 必须与数据库当前名称一致；
名称冲突返回 409，未知身份返回 404，空白、超长、缺失前提或额外身份字段返回 422。
在数据库事务中只更新显示名称，不新建参与者、不改变 QQ 关联、场景听众、
会话 ID、记忆或状态范围。相同名称不会合并身份。

弹窗增加“修改当前参与者名称”。保存后当前下拉列表和听众列表同步显示新名称，
关闭窗口会取消客户端等待；晚到的响应不能改变已关闭或重新打开的弹窗。
服务器已提交的改名不会因客户端取消而回滚，下一次读取以服务器为准。
名称冲突会提示重新打开窗口读取；没有静默重试覆盖。

现场占位名按既有账号 / QQ 号 / participant 关联读取并改为 QQ **昵称**。
“主人”“睦月”等已有手工名称保留。全局参与者名称不使用群特有名片，
不按昵称推导身份或权限，也不自动持续覆盖手工别名。

## 界面

原弹窗通过 Portal 渲染到 body，不在上一轮设置页样式范围内。
现在显式加入共享控件范围：40px 常规输入、选择器和文字按钮，10px 圆角，
13px 字体，一致的箭头、边框、禁用态和可见键盘焦点。

标题、关闭按钮与底部取消 / 应用按钮固定；正文在窗口内滚动。
创建 / 改名表单使用分组折叠卡片和可见字段名，听众使用有滚动上限的成员列表，
16px 复选框、选中反馈及 2–32 人计数。删除重复旧 CSS 与原生 fieldset 方框。
最近一次未提交的名称和听众草稿不跨重新打开窗口复用。
保留焦点锁定、Escape、背景 inert 和通话关闭行为。
打开入口通过显式元素引用记录，解决 WebKit 鼠标点击不聚焦或 inert 导致失焦时，
关闭不能返回入口的问题；既有其他弹窗继续使用原有默认行为。
