# 设置中的知识图谱

打开“设置 → 记忆与资料 → 知识图谱”，再点击“打开知识图谱”。图谱以独立页面
打开，拥有完整画布、搜索、关系筛选、记忆与事项、来源原文及冲突处理入口。
点击图谱右上角“返回设置”回到该设置分类。

Web 在同一标签页中跳转，保持当前连接的登录会话。桌面设置显示当前 Runtime 的
图谱网址，在浏览器中打开；浏览器首次使用时需登录，不会将桌面令牌放进网址。
图谱继续只允许本人私有会话，其他参与者或共享场景不能借设置入口访问本人资料。

设置搜索支持“知识图谱”“知识地图”“关系”“来源”“冲突”；登录设置支持
“密码”“令牌”“登录”“认证”。服务器尚未提供知识 API 时，页面会明确提示
需要启用知识库服务，而不会将接口缺失当作没有资料。

源码服务器可通过私有运行配置指定 `runtime.web_client_dir`，或设置
`CHATWAIFU_RUNTIME__WEB_CLIENT_DIR`，发布以 `/web-client/` 为 base 构建的 Web
目录。这样公网根地址、`/settings/knowledge`、`/settings/connection` 与
`/knowledge` 都能打开实际登录/产品界面，数据 API 仍要求认证。
