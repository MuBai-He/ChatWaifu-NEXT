# 使用密码连接 Runtime

1. 首次连接时，在连接页选择“访问令牌”，使用服务器已有的令牌进入。
2. 打开“设置 → 连接与诊断 → 登录密码”。输入新密码和确认密码，点击“设置密码”。
3. 此后在连接页选择“密码”，输入服务器地址和登录密码即可。Web 和桌面端均支持。
4. 修改密码时，在同一位置输入当前密码、新密码和确认密码，点击“修改密码”。

新密码支持 12-128 个字符，中文、空格、符号均可；首尾空格也属于密码。
密码只以加盐哈希保存在 Runtime 配置目录。浏览器只在当前会话保留交换得到的
登录凭据；桌面端按现有连接配置规则保留凭据，不保存密码。

密码登录有效期为 24 小时。Runtime 重启后需要重新登录。修改密码后其他设备需
重新登录；当前远程客户端会保存新的登录凭据。已有访问令牌继续可用。
连续尝试最多每分钟 5 次，超出时等待后重试。若其他设备已修改密码而设置页仍
显示旧状态，点击“重新读取密码设置”再填写。

HTTPS 和受信任的局域网 HTTP 地址规则与现有连接页一致。服务端仍执行 Host、
Origin 和单次 WebSocket ticket 检查。密码登录不会取得 `admin_events` 的专用权限。

## API v1

| 方法 | 路径                         | 请求                                                                       | 响应                                          |
| ---- | ---------------------------- | -------------------------------------------------------------------------- | --------------------------------------------- |
| GET  | `/v1/runtime/password`       | 已认证                                                                     | `schema_version: 1`, `configured`, `revision` |
| PUT  | `/v1/runtime/password`       | 已认证；`new_password`, `expected_revision`；已设置时需 `current_password` | `schema_version: 1`, `token`, `expires_in`    |
| POST | `/v1/runtime/password/login` | `password`                                                                 | `schema_version: 1`, `token`, `expires_in`    |

响应禁止缓存。错误密码返回 401，旧版本写入返回 409，限流返回 429 与
`Retry-After`；验证错误返回经过脱敏的 422，存储失败返回 503。
接口不会返回密码或密码哈希。

如果忘记密码，需在服务器上停止 Runtime，备份配置后仅移走
`runtime-password.json`，再启动并使用原访问令牌设置新密码。不要删除数据库、
其他配置或凭据文件。

此功能的源码验证与服务器发布、原生安装包更新分别验收。

## 可重复的本地验收

在一个终端启动独立测试 Runtime，测试状态会写入新建的临时目录：

```sh
uv run python tools/password_e2e_runtime.py --port 18886
```

在另一终端运行真实连接页验收。专用配置不会使用开发环境的免登录入口：

```sh
PASSWORD_E2E_RUNTIME_URL=http://127.0.0.1:18886 pnpm --filter @chatwaifu/web exec playwright test --config playwright.password.config.ts
```

每轮浏览器验收使用新启动的测试 Runtime。测试覆盖首次令牌连接、设置密码、
错误密码、修改密码、旧凭据失效、新密码重连及宽屏/手机布局；客户端存储中不含
输入的密码。自动化测试使用公开的临时测试凭据，不接触实际服务器配置。
