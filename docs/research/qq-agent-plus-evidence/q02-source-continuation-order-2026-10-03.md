## 实现

新增内部 `LlmRequest.continuation_system_prompt`，承载 Runtime 自己生成的后续指令。
OpenAI-compatible 适配器把它序列化为历史、用户输入、工具结果之后的系统消息；不伪造用户输入，
不把网页指令提升为系统指令。参考 token 估算复用实际消息构造，所以新增指令也计入输入预算。

来源工具循环以该字段要求读取原文、必要时重新搜索原始文档、核对后续更新。最终来源修订也使用
该位置，取代追加在开头系统消息里的修订要求。修订仍只有一次、没有可执行工具，保留取消、
过期 generation、必需输入超限与未完成输出检查。普通对话和无来源的工具流程保持原有方式。
原有六次来源工具调用上限未增加，生产 persona、模型路由、预算与数据库未变。
