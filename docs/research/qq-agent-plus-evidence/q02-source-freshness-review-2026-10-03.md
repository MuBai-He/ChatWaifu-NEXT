# Q02 来源时效性复核：不得把旧公告完整性等同于现行规则

这是完整批次运行期间独立取得的审查依据，未注入运行中的模型请求，也没有中途
修改其夹具、答案或判定门槛。既有门槛本来就要求核实适用时间、后续修订和来源
范围；旧的 3C/召回关键词覆盖审计不能代替这一要求。

ICAO 的 [2026 年增补说明](https://www.icao.int/zh-hans/filebrowser/download/92841?fid=92841)
明确区分充电宝与其他备用电池：每位旅客至多两个充电宝的限制不取决于其容量，
同时禁止在机上给充电宝自身充电。该说明仍列出经经营人批准的 >100Wh、≤160Wh
例子，因此不能从数量新规反推出这一能量档一律禁止。

国航 [2026-08-04 提示](https://www.airchina.com.cn/zh-CN/content/c/2026-08-04/30035.shtml)
实际写明每位旅客至多两个充电宝，保留 100Wh/160Wh 与航司批准的分档；同时列出
中国境内航班清晰 3C 标识、召回/外观损坏/无法确认能量禁运、随身与绝缘防护、
机上摆放及使用限制。这是国航的明确现行运营要求，不能未经核实扩大为所有航司
每项细节均相同。

据此，若回答只引用 2014 年基础公告或 2025 年 3C 公告，却宣称已经核对 2026 年
完整现行规则，证据仍不足。也不能把“两块”只附着于 >100Wh 档，再推导低容量
不受数量限制。完整批次将区分：忠实复述取得的旧原文、明确标注时效性缺口、实际
取得后续修订，以及把旧材料说成完整现行规则。来源发现与模型解释分别归因。

服务器随后使用同一 v7 CW2 适配器、现有 SearXNG 与 Crawl4AI 0.9.2 完成独立探测，
[原始请求与收据](q02-full-sx-crawl-2026-10-03/independent-freshness-probe/results.json) 已保留：

- `2026 国内航班 充电宝 最新 规定`：3.240 秒，前五项混有无关页面与旧资料；未发现上述新公告。
- `site:airchina.com.cn 2026 充电宝`：0.651 秒，前五项是购物商城/商品页面；同样未发现新公告。
- 已知国航公告 URL：Crawl4AI 1.888 秒成功读取 1339 字符，无截断；收据使用 `dns_resolver=cloudflare`，正文包括日期与完整规则。

这里已有服务器证据表明来源发现/排序不足，读取器能处理该新 HTML。已知 URL 的读取
不能算作自主搜索成功，也不能据此宣称所有网站都能读取。该独立探测未向正在运行的
完整批次补答案；Q02 未因此获得通过。


## 隔离 SearXNG 上游与代理对照

原服务仍在18080，仅启用Yandex。使用同一镜像另建18081测试实例，保留原始
[探测结果](q02-full-sx-crawl-2026-10-03/engine-probes/)，没有更换生产引擎或关闭TLS校验。

- 原配置未设置 outgoing 代理。默认3秒时 Google/Brave/DuckDuckGo超时；放宽到12秒后，
  Google和DuckDuckGo明确报证书验证失败，Brave仍超时；Sogou报引擎异常，Bing空结果。
- 显式通过已存在的服务器Mihomo HTTP代理后，Google变为access denied，Brave为429；
  DuckDuckGo和Bing能够返回结果，说明此前网络路径确有影响，但HTTP成功仍不等于相关。
- Bing把两条含2026的中文问题返回为日本日历、Raft问题返回游戏页面，不能据此采用。
- DuckDuckGo首次站点查询把国航2026-08-04公告排在首位；Raft原论文查询也得到官方PDF。
  但后续7查询×3重复中仅3/21次返回结果，18次出现CAPTCHA，不能宣布稳定或直接替换生产。
  未尝试绕过验证码，未轮换代理出口。
- 360search直连和代理均能返回结果，国航站点查询可找到服务公告索引，但这次泛查询没有
  直接找到新公告；Yandex仍以商城结果为主。两者需要按实际来源覆盖评审。

另确认CW2原有SearXNG当前信息分支把任意URL、标题或片段里的日期当作主排序键，
可能把无关新页面挤入前五。v8只移除该分支的日期强制重排，保留上游相关性顺序与
已有域名/安全过滤、互补查询交错。旧实现的新回归用例失败，新实现通过；此修复不能
补出供应商没有检索到的来源，也不等于已解决验证码或其他Provider的排序问题。

## 后续组合与真实模型验证

候选 SearXNG 改为 360search + Yandex、使用现有 Mihomo HTTP 代理后，四条官方站点查询
各三次均返回结果（12/12，无 unresponsive 引擎）。360 找到国航 2026-08-04 公告，Yandex
补充 Raft 原论文及 Python 原始文档；这仍只是短期固定查询覆盖，不能宣布长期稳定。
泛查询和真实模型选择的查询仍会漏掉后续公告，搜索关键词决定检索覆盖，已知 URL 可读不能
替代自主发现。新增探测见 `engine-probes/results-combined-repeat.jsonl` 与
`engine-probes/results-broad-currentness.json`；后续 Runtime 改动与真实失败见
[指令位置对照](q02-source-continuation-order-2026-10-03.md)。
