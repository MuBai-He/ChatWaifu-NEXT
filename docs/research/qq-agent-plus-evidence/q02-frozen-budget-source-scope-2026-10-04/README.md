# 本轮证据索引

这是一轮预算、读取恢复及来源范围调查，**Q02 未通过**。真实模型均从服务器调用配置的 Gemini 3.8 Flash High；没有 AGY/Jina、生产部署、渠道或 TTS 操作。

- `frozen-budget/`：v28 服务器实际 payload、逐尝试用量、结果、三条新增原文对照，以及独立搜索/读取诊断。首次非法搜索参数失败仍保留。
- `budget-analysis/`：旧失败请求的离线重建、分项体积反事实、隐藏条件主审/揭示、十二条模型回复的账目与来源范围审查。
- `reader-v29/`：读取补救后的真实四轮试验。两条结果中一条为 Runtime 回退，第三轮失败、第四轮未执行。
- `scope-v30/`：两处范围/历史收据修复后的新冻结批次，第三轮响应处理失败与单次精确 payload 重放。重放不执行工具，不计作场景恢复。
- `runtime/`：跨 v29/v30 的每次请求、未知用量、实际摘录覆盖和逐条作者主审。
- `validation/`：失败回归、修复检查、完整 Python、类型/构建与服务器最终边界验证。

远端原始 manifest 的 `.py` 文件在这里保存为 `.py.txt`。`publication-input-manifest.json` 记录原文件名和相同字节的 SHA-256；核验原 manifest 时先使用这一映射，不能因更名报内容不一致。研究脚本文本记录原运行方法，含临时目录路径；若需重现离线审计，将其复制/更名到隔离临时目录并配置仓库 Python 路径。不要把保存的研究脚本直接作为生产部署或新模型调用指令。

原始服务收据、正文、截断及时间都是证据；Provider `stop`、输入未超限、Reader HTTP 200 与全计划质量通过不是同一条件。主审为实现作者复核，只有前九条先隐藏条件再揭示，不称独立双盲。
