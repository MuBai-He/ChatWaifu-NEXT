## 行为和边界

输入 `max_links` 为 0–20，默认零，旧调用仍只读取原页。明确请求后返回实际 anchor URL、可见 label 及 label 截断标记。单一明确正文继续限制链接来源；正文不明确时沿用可见文档回退。`links_scope: selected_source` 指选定正文/文档，链接可能位于返回文字片段之外，不能凭文字片段猜它不存在。

相对地址使用最终抓取 URL 与第一个 head base 地址解析；多个 base 不覆盖第一个。忽略 base 的初版会构造错误的同站地址，审查后修正并补回归。base 和目标只是未核实的地址数据，不触发 DNS 或抓取。实际 HTTP 链接保持 HTTP，不生成 HTTPS 替代地址，也不放宽原 HTTPS-only reader。后续每次读取仍须原权限/确认，并重新验证公开地址、TLS、重定向和固定 DNS。

隐藏、脚本、导航、空 label、凭据 URL、非 HTTP(S)、非标准端口及明显本地地址不进入链接结果。最多二十项，序列化各项合计最多 3000 UTF-8 bytes，去重并保留文档顺序；count/bytes 省略有 `links_truncated`，label 最大 240 字符并有独立标记。不会执行页面指令或跟随链接，也不宣称目录完整。旧收据缺新字段表示未知，兼容的 output schema 新字段可选；实际新 adapter 始终返回请求/范围/截断状态。

评测器升级 **1.9.2**，其既有指纹包含 reader、manifest 和 Skill 文档，拒绝旧实现混续；上下文身份的工具 schema 摘要自然改变，没有新增公共协议字段。来源收据仍经原只读端口和整份预算投影，不把链接写进长期记忆或常规持久审计。
