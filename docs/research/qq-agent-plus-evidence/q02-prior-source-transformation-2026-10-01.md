## 修复及边界

Agent 只检查当前用户输入：明确提到先前资料、要求整理/摘要/清单，并且来源端口提供成功、原文可用、正文非空的 host web.read/read 收据，才撤去本轮 incidental tool schemas。搜索片段、失败或重启/淘汰后不可用的原文不能满足条件；来源正文和旧助手措辞不能决定操作意图。输入仍经过完整角色、独立不可信来源 JSON、冻结完整预算及取消检查。

明确的重新查询、最新规则、额外 URL、创建/修改/发送/保存等操作，以及“提醒我明天检查”，继续使用工具与既有权限流程。只是保留“仍需核实的提醒”不会触发新的提醒写入。该判断是保守的中英文有限措辞支持，不能代替通用语义理解；不确定表达仍走普通路由，也不保证旧公告适用于当前。没有新协议、数据库或长期来源存储。见 [ADR 0060](../../adr/0060-bounded-cross-turn-public-source-context.md)。

实际两轮 Conversation 回归先经 allow_once 完成一次 READ，第一轮助手只说读过，没有复述条件。修改前整理请求多出必需工具回合；修改后完整原文、URL 和读取时间在 user-role 中保留，Provider 总请求为三次，READ 仅一次，审计不保存原文。重新查询及自然提醒请求仍投影 required tools；自然提醒的修改前反例有三项失败，修复后控制通过。既有会话/路由隔离、预算、不可用来源和取消断言保留。
