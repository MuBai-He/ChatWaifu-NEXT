## 失败语义与工具结果

新增 Provider 中立的 `LlmEmptyResponseError`。Agent 在收到终态且没有非空白正文时抛错，覆盖普通文本、成功读取后的收尾、写入后的收尾及工具次数/输入预算关闭后的文本路径；保留流式文字和缺失终态的原有处理。过期 generation 先按取消处理，不变成空回复失败。全部读取失败时仍走已有诚实说明。

ConversationService 将 generation 保存为 `failed`，错误码为 `empty_model_response`，不保存成功的空助手回合。已有工具结果不回滚、不自动重放；带记录工具交换的空回复错误不标为可安全通用重试，纯文本空回复仍沿用可重试失败语义。没有新增模型纠正或 fallback 请求。

评估器升级为 1.6.2：直接 Provider 和 opt-in Agent 路径都把空白终态保留为 incomplete，记录实际 usage 或完整 Runtime trace，停止该批而不保存伪成功样本。原失败和旧版本评测不会混入新批次。

真实 Agent 对照复用了已冻结的来源交换，没有执行新的读取、写入、权限确认或生产会话。Agent/contracts/评估器哈希与当前代码一致；此后为保留已有 Vision 错误调用形状，将重试策略移到 ConversationService 的统一失败处理，因此该文件哈希不同。真实模型对照没有执行 ConversationService；最新生命周期另由两个实际隔离 Runtime 测试验证，不能将二者混称为真实模型全链路验收。
