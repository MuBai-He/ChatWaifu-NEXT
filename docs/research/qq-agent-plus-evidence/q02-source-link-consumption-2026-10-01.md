## 实际失败与归因

每个隔离会话先明确读取民航局要闻目录并保留二十个链接，再要求从实际返回的“信息公开”链接继续读取；后两轮明确只分析现有页面，不再调用工具。完整原始流式事件、输入 hash、上下文身份、操作、权限决定和各项判断见[本批证据](gemini-source-links-consumption-evidence-2026-10-01.json)。

- 三次目录 READ 成功，实际标题与 HTTP 新闻地址被正确保留，未声称读过新闻正文；但三条回答均误称 HTTPS-only reader 可以直接读取 HTTP 链接。目录的链接提取真实，能力说明错误。
- 三个后续初始请求都将目录整份原文标成 `omitted_for_input_budget`；旧 metadata 只有目录 URL，没有实际子链接。模型三次请求重读目录。评测守卫只允许用户指定的目录和实际选定的子链接，拦住这三次重放，零 child HTTP。**不是子页面网络失败，也不证明生产环境绝不能通过额外重读取得子页**；实际输入确实失去已有链接，造成不必要重放。
- 三个“只根据现有原文、不要工具”的证据缺口问题仍进入 required。即时消息产生一次无调用回退；普通文本和 voice-origin 在纠正后发起原生 READ，确认均拒绝，零 HTTP。模型原本生成的分析没有成为可见回复，属于 Runtime 决策误阻断；没有把这两次被拒绝请求说成实际联网。
- 最终清单三条保留“新闻未读、现行规则缺证据”，但两条混淆评测守卫与权限/访问限制。未以目录无规定文字推导现实中没有规定。

目录实际是可见文档回退，正文 2558 字符未截断，链接列表二十项且 `links_truncated=true`。目录不是当前法规全文。三次成功公开 HTTP 链路均无 Authorization/Cookie，所有隔离 Runtime 正常停止，零持久授权。voice-origin 只输出文本，没有麦克风、TTS 或设备播放。

## 修正范围

`web.read` **1.3.0** 的实际结果声明 `read_url_schemes: ["https"]`，与可能为 HTTP 的未核实 anchor 数据分开；output 字段可选以兼容旧收据，旧缺字段表示未知。Agent 工具政策要求保留真实 scheme、遵守声明的 reader 限制，不猜 HTTPS 等价地址；权限、公开 DNS、TLS 和后续确认不变。

跨轮来源投影允许实际有界链接及其请求/截断/范围、reader 限制作为 metadata 留存，即使完整正文因预算被省略。链接列表整份保留或与 metadata 一起明确省略，不截正文、不补造链接、不宣称目标已读，也不将这些资料写入长期记忆或扩大常规审计。来源主体仍是实际成功 READ 的收据，读取权限不继承。

当前用户明确限定“只依据已有/所给内容”并同时禁止新工具时，不因提到法规、天气或价格就强制获取新事实，模型只分析现有证据。缺少原文仍有缺口，不能靠工具静默补取。中英文的明确复合读取、保存、发送和提醒继续优先走 required；规则只读当前用户输入，不从来源或助手措辞推断授权。仍是有边界的语言政策，不是任意措辞的语义保证。

prompt identity 更新 **v8**，评测器 **1.10.0** 拒绝混续；更新 ADR 0061，不增加协议字段、数据库迁移、搜索供应商或生产授权。
