## 范围与实际路径

Conversation 在历史脱敏与 PromptCompiler 选择后，最多选择八个同一路由的助手 generation，并核对当前 session 与 completed 状态。路由使用渠道、连接、账号、principal、聊天类型、会话、发送者与受众的稳定键；显示名称和收到时间不参与授权。跨会话 ledger、其他路由、未知 ID、未完成生成和被脱敏回复均不提供正文。

通过内部版本 1.0 的只读端口，Runtime Skills 查已有 SkillRun，限定 agent origin、宿主 builtin 执行计划、web.search/search 或 web.read/read，排除插件、MCP、手动和其他能力，最多返回 32 个终态收据。原文只来自已有 64 项 ephemeral result 缓存；读取不会重新执行工具、延长缓存顺序或创建持久授权。结果深拷贝，查询只经领域持久化端口。见 [ADR 0060](../../adr/0060-bounded-cross-turn-public-source-context.md)。

Agent 将可信处理规则与 user-role 的不可信 JSON 资料分开，普通文本和工具决策/收尾均使用该资料。成功表示取得资料，不能直接等同于当前有效或完整；搜索片段仍需读取原文。后续总结保留相关条件、例外、实际链接及待核实事项。

完整请求按冻结的离线参考额度计数。正文整份保留或明确省略，不能截取一半冒充完整来源；省略正文时保留可用来源元数据，元数据本身过大则从较旧项开始明确省略，读取终态始终保留。必需内容仍无法容纳时使用既有预算说明，零 Provider dispatch。原生 Claude/Gemini 用量上界继续未证明。

## 失败回归与受控验证

修改前的真实两轮测试经过 allow_once 权限确认，第一轮读取完整合成规则，助手只答“读过了”；第二轮实际请求仅收到这句旧回答，原始条件缺失。修改后检查实际请求，原文、URL、读取时间和截断状态进入独立 JSON 资料，且不成为 system 指令。工具只执行一次，审计行仍没有原文或带私有查询值的 URL。

另一个审查回归发现十条长来源 URL 使参考输入达到 16431，超过测试冻结额度 2400。加入元数据省略后保留所有收据 ID/终态与明确 marker，完整投影符合原额度；没有提高额度或裁剪正文。

十种真实 Conversation 控制覆盖可用正文、真正重启、超过缓存容量、真实 reset、权限拒绝、另一会话、历史 cancelled/failed/running 状态，以及在来源加载时取消后零 dispatch。路由控制覆盖全部八个稳定键、显示名称变化、脱敏、未知 ID 和选择上限。另覆盖完整结果高于旧助手措辞、超大 Unicode 正文、原文不可用和仅输出规范错误码。

评测器 1.8.0 为完成/续跑的合成助手历史保留 generation ID，并使用同一个端口与 Agent 投影。实际 helper 受控读取后续简表保留来源/拒绝状态，零重复读取和持久授权；来源加载前取得单轮执行锁，取消会释放锁。新增代码纳入实现指纹，禁止混合续跑；重启后的旧结果诚实标为不可用，不从生成文本或旧报告恢复正文。
