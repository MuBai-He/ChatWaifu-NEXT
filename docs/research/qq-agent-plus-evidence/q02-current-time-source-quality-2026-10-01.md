# Q02 本轮时间与来源时效

2026-10-01。上一批真实工具循环中，Sonnet 限定查询 2024 年，Opus 读取 2014 年公告。代码检查确认 PromptCompiler 未提供可信本轮时间；这是一项上下文缺口，不能单凭它断言旧来源选择的全部原因。

本切片沿用 ConversationService 与 PromptCompiler：从已经持久化的 Runtime 受理事件取得时间，纳入不可变 GenerationContextSnapshot，在模板 v3 的系统安全上下文中按 UTC 提供。编译器计入时间文本 token，拒绝无时区时间以及对已有快照的时间覆盖。用户消息、渠道显示标签和来源抓取时间均不能设定这个时间。旧来源的发布日期、生效日期和后续修改仍需实际查证，不能以“现在日期”推导规则。

Agent 通用来源规则优先责任机构原文、已知官方域名、后续修改与生效范围；当前问题不随意限制到过去年份，原文读取失败时不以摘要冒充核实。没有添加场景答案、特定监管 URL 或按问题名称分支。

评估器升级 1.4.0，`--prompt-as-of` 接受带时区的 ISO 时间并归一 UTC；远端新运行默认冻结启动时刻，Demo/受控模型默认使用合成夹具时间。恢复时复用已保存的时间；显式改时刻、模板/实现指纹或版本变化拒绝混跑。`prompt_as_of` 与固定关系状态时间 `state_time` 分开记录，A/B 与三个模型须显式共用同一个时间。历史付费回复和原始评审文件不回写。

没有新增数据库表、公开协议字段或后台时钟服务。PromptContextIdentity 仍为 1.0，动态时间不参与配置身份 hash，模板变化用 v3 标记；重新生成 JSON Schema/TypeScript/Zod 未产生差异。时间可追溯至已有受理事件。逐次来源权限、即时取消和外部渠道禁用工具的规则保持现有边界。

## 失败复现与验证

- Windows CI 的实际失败是新增评测测试使用默认 CP1252 解码 UTF-8 journal。在 macOS 对同一路径模拟该默认编码，旧读取失败、显式 UTF-8 后通过；没有改全局编码、CI 参数或断言。
- 新时间回归在旧实现失败：受理时间未进入提示、编译器/评估器不接受显式时间。修复后验证跨午夜及跨异步等待保留旧时间、下一轮采用新时间、时间变化不改变配置身份、UTC 归一、无时区拒绝和续跑不重复调用。
- 定向 82 项通过；Python 全集 1646 通过、46 个 Windows 专属用例在 macOS 跳过；Ruff lint/格式与 Pyright 通过。其他构建、真实模型及远端 CI 结果另行登记。
