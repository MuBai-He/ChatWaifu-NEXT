- 为 QQ 主人私聊和 `931709239` 群启用表情学习，支持原生系统表情和原生收藏。

## 冻结行为与边界

私聊普通图片的描述符最多保留 60 秒，同一连接、账号、主人和 durable binding 的下一条普通文字可使用一次。
它使用新轮次的身份与内容摘要；旧生成仍取消，旧输出不能继续发送。
重复事件不刷新期限、不重新下载或生成，后续新轮次不再继承。
新图片替换引用，失败丢弃引用；引用消息和音频不继承，带引用的图片也不建立这类后续引用。
最多 32 个 binding 保留描述符。手动取消、连接配置成功变更、删除、断连和停止同步清除；错误的 revision CAS 不清除仍有效的引用。
重启不会从 QQ 历史恢复引用。借用后的下载前后均检查撤销和当前主人授权。

群引用也只保留描述符，未 @ 的图不会触发下载、生成、转录、记忆或保存。
同一成员在 60 秒内 @ 后，才按当前账号、成员授权、场景和学习设置读取；其他发送者、群或后续轮次不能借用。
这只补近期图片关联，群文字历史仍由已获准的 @ 对话构成。

GIF 按实际字节识别，仅解码有界首帧。单帧 GIF 可参加静态学习；多帧 GIF 当前只做识别预览，不能声称理解后续帧或已经收藏了动画。
静态素材仍需保守分类、源轮次完成、去重和删除 fence；群保存还需在 SQLite 事务中复核当前 route/scene/audience/speaker。
群发送最多在必要文字之后追加一张本场景的可选图片，分别保留文字和图片的投递终态。

原生 `face` 来自小型精确 Unicode 映射，保存图片使用 `sub_type=1`。
原生收藏使用认证的有界上传、自己上传的文件名、添加前未知结果检查点以及 MD5 回读；未知结果不自动重试。
原生收藏失败不破坏 CW2 学习保存和文字回答。QQ 原生收藏属于账号，删除 CW2 资产不会自动删除账号收藏。

SQLite 42 只调整群交付 part 插入约束；先前迁移与事实保留。41 二进制不能重新打开 42，需要使用兼容代码；部署前的一致性备份保留在服务器私有目录。
设计见 [ADR 0074](../../../adr/0074-scoped-qq-sticker-learning.md)。
