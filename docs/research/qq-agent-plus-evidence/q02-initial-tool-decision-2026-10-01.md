## 实现与边界

PromptCompiler 模板 v4 额外产出安全/同一受理时间子集。ConversationService 与评测器通过可选内部 `LlmRequest.tool_decision_system_prompt` 传给既有 Agent；旧调用者没有该字段时沿用原路径。初始必需调用及已有的一次纠正使用该子集和通用操作决策规则。先前用户历史保持原位置，先前助手文本以明确的不可信 JSON 资料进入上下文；必要时省略最旧助手文本并标记，初始 system/context/history 字符总量不超过原输入。

首个实际工具交换后恢复完整角色提示及原始 context/history，普通聊天从一开始使用完整提示。用户文本、图像、冻结路由、generation 和工具 schema 保留。执行仍通过 Registry → PermissionBroker → Executor，权限检查实时生效；四次工具与六次 Provider 上限不变。没有新的模型路由、公开契约字段、权限授予、数据库迁移或特定场景答案。

所有已尝试读取均失败、模型不再请求工具时，Agent 丢弃它的未核实文本，返回查询未成功的说明；规范化 `permission_denied` 另外说明未获授权，不复述任意错误正文。四次读取全部失败时直接返回，无额外最终模型请求。后续 Provider 不支持工具也不能称“已完成查询”。混合成功/失败仍允许总结已有成功结果；写后关闭工具的既有行为保持原样。

评测器当前为 1.5.2，补入请求契约实现指纹，记录实际 context/history hash，保留失败与被丢弃回合的真实 usage。旧证据不混跑。模板版本和角色包版本独立，默认 persona 仍为 v4。
